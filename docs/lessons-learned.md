# Lessons Learned

## Overview

Deploying a multi-node K3s cluster on AWS provided practical experience with Kubernetes, Linux, networking, storage, and cluster management.

## Key Lessons

### Kubernetes Cluster Management

I learned how a Kubernetes control plane manages worker nodes and how to verify node health using `kubectl`.

### Networking

I gained a better understanding of private IP addresses, Kubernetes service networking, pod networking, and Flannel.

### Node Authentication

I learned how K3s uses a node token to securely authenticate worker nodes when joining the cluster.

### Storage

Working with the Local Path Provisioner and PersistentVolumeClaims helped me understand how Kubernetes manages persistent storage.

### Troubleshooting

The project reinforced the importance of checking logs, events, node status, and network configuration before making changes.

### Portainer

Using Portainer gave me hands-on experience managing and monitoring a Kubernetes environment through a graphical interface.

## Key Takeaway

This project strengthened my practical understanding of Kubernetes and demonstrated the importance of networking, security, storage, documentation, and systematic troubleshooting in a DevOps environment.
